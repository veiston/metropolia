List of TempleOS programs:

Program Description
Adam The Ring-0 initialization task. Written in JIT-compiled HolyC, it compiles the rest of the OS upon boot, acting as the system's foundational genesis.
Ed / DocEd The universal text and code editor utilizing the DolDoc hypertext format. It enables live 3D meshes, flowcharts, and macros directly inside plaintext source code.
FileMgr The native file manager, tightly integrated with the system shell and designed exclusively for navigating the continuous-allocation RedSea file system.
After Egypt A spiritual application functioning as a digital oracle. It polls a high-speed hardware stopwatch as an entropy source to generate pseudorandom text for communicating with God.
GodSpeak A minimalist divine oracle that outputs random words and phrases from the system's built-in dictionary based on timer-tick entropy.
Psalmody An algorithmic music sequencer that generates randomly composed monophonic hymns using only the motherboard's internal PC speaker.
EagleDive A flight simulation game demonstrating the OS's native 3D software rendering capabilities within its locked 640x480, 16-color VGA mode.
Castle Frankenstein A first-person shooter built entirely from scratch to showcase real-time 3D rendering and physics without any GPU acceleration.
X-Caliber A 3D melee action game demonstrating real-time mesh rendering, input polling, and collision detection operating continuously in Ring-0.
Titanium A top-down arcade shooter showcasing 2D sprite handling and an efficient, uninterrupted kernel-level game loop.
